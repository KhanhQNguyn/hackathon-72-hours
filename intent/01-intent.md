# intent.md — [Product Name]

## Starter prompt (dùng để mở phiên làm việc với Claude)

> "I want to build a [Product] to solve [X] problem. I'll walk through my rough idea, and I need you to generate an intent.md file to capture the details. After that, we'll keep discussing it in more depth, and I need you to continuously update intent.md after each topic we cover (Problem → Users → Outcome → Features → Constraints → Success Criteria → Open Questions → Rubrics) — update only the relevant section each time, don't rewrite the whole file."

## Process

1. Describe the idea in plain, non-technical language — what problem you want to solve.
2. Work with Claude through follow-up questions to clarify: users, problem, scope, constraints, success criteria.
3. Claude synthesizes this into a standardized intent.md file.
4. Read it carefully, correct anything Claude got wrong, add missing requirements, cut anything unnecessary.
5. Once agreed, commit the file to Git → officially move into the spec.md phase.
